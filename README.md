# Lunar Landing Analyzer — ONLINE COMPETITION V3
GitHub Pages-ready static build.

NEW IN V3:
- Visible 3D Moon, Earth and Sun.
- Lunar-cycle time slider (0–29.53 days).
- Live sunlight, solar elevation, Earth visibility and temperature screen.
- Click the Moon to choose a landing site.
- Site pros, risks, score and Earth analogue.
- Add multiple candidates and compare them; the highest scoring candidate is highlighted.
- No backend required.

PUBLISH:
1. Upload index.html, app.js and style.css to the repository root.
2. GitHub → Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: main / (root).
5. Save and open the Pages URL.
